# Adrobot

Обёртка над Keitaro Admin API для создания кампаний и редактирования офферов в потоках. Интерфейс на React, TypeScript и Vite. Сервер на FastAPI с SQLAlchemy, SQLite и миграциями Alembic.

## Запуск с нуля

Понадобятся Python 3.11+, Node.js 20.19+ или 22.12+ и действующий ключ Keitaro Admin API с доступом к тестовым кампаниям. Команды ниже рассчитаны на macOS и Linux.

В корне проекта скопируйте настройки в `.env` и заполните `KEITARO_API_KEY`. Если `.env` уже существует, отредактируйте его.

```sh
test -e .env || cp .env.example .env
```

| Переменная | Назначение |
| --- | --- |
| `KEITARO_BASE_URL` | Адрес трекера без `/admin`. В примере указан тестовый стенд. |
| `KEITARO_API_KEY` | Ключ Admin API. FastAPI читает его на сервере из `.env`. |
| `DATABASE_PATH` | Необязательный абсолютный путь к SQLite. По умолчанию `adrobot.sqlite3` в корне проекта. |

В репозиторий входит только `.env.example` с пустым полем ключа. Храните действующий ключ в локальном `.env`.

Установите зависимости Python, примените миграции и запустите сервер из корня проекта:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -e ./backend
.venv/bin/alembic -c backend/alembic.ini upgrade head
.venv/bin/python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

Во втором терминале из корня проекта:

```sh
cd frontend
npm ci
npm run dev -- --host 127.0.0.1 --strictPort
```

Интерфейс доступен на [127.0.0.1:5173](http://127.0.0.1:5173), документация FastAPI — на [127.0.0.1:8000/docs](http://127.0.0.1:8000/docs). Vite проксирует `/api` в FastAPI.

После обновления проекта снова выполните `alembic upgrade head` с тем же `backend/alembic.ini`. Проверить применённую версию можно командой:

```sh
.venv/bin/alembic -c backend/alembic.ini current
```

## Проверка сценария

1. В разделе **Создать кампанию** введите название с префиксом `test_фамилия_`, двухбуквенный код страны и ID активного оффера. Выберите домен, группу и источник из справочников. На тестовом стенде использовались `MX`, оффер `18813`, домен `kylovoa.com`, группа и источник `FORTESTS`.
2. Создайте кампанию. По умолчанию она остаётся выключенной. Обычный поток принимает трафик из выбранной страны и отправляет на Google. Замыкающий поток содержит заданный оффер с долей 100%. Если выбран переключатель **Включить после создания**, сервер активирует кампанию после проверки её настроек и обоих потоков. При частичном сбое форма показывает ID созданной кампании и этап ошибки.
3. Нажмите **Открыть редактор**, затем **Fetch Streams**. Можно также ввести ID уже существующей тестовой кампании. Потоки без офферов отображаются по названию. Для потока с офферами доступен редактор привязок.
4. Введите ID другого доступного оффера и нажмите **Add**. При добавлении, снятии или восстановлении оффера остаток делится между активными офферами без закрепления. **Pin** сохраняет текущую долю. Если деление оставляет целочисленный остаток, дополнительные пункты получают офферы с меньшим ID. Например, три равные доли — `34/33/33`. После закрепления `34%` и добавления четвёртого оффера получится `34/22/22/22`. Если в каталоге доступен только один активный оффер, этот пример можно воспроизвести на тестовых данных.
5. Кнопка с иконкой корзины (**Remove**) оставляет привязку в черновике с долей 0%. **Bring back** возвращает её, **Cancel** восстанавливает последний загруженный состав. Повторный **Fetch Streams** сохраняет открытый черновик. Если привязку сняли напрямую в Keitaro, повторная загрузка переносит её в локальный архив. При открытом черновике редактор сообщает об изменении, а **Cancel** показывает обновлённый архив.
6. **Push to Keitaro** сверяет текущие привязки с исходным снимком. Если требуется запись, сервер отправляет список и отдельно перечитывает поток. После подтверждения состава и долей черновик закрывается. При конфликте или ошибке он сохраняется. На выделенной выключенной кампании можно опубликовать снятие оффера, затем вернуть его через **Bring back → Push to Keitaro** и проверить итог в Keitaro.

## Хранение и проверка сборки

Если форма сообщает о пустом справочнике, проверьте доступность доменов, групп и источников для аккаунта Keitaro, затем нажмите **Повторить загрузку**. Существующую кампанию можно открыть в редакторе по ID.

SQLite хранит последний снимок каждой загруженной кампании, черновики, архив привязок и закрепления. FastAPI следует запускать с одним worker для последовательной обработки локальных изменений и публикаций одной кампании. Проверка внешнего состояния и запись в Keitaro выполняются отдельными HTTP-запросами.

Из корня проекта:

```sh
npm --prefix frontend run build
.venv/bin/alembic -c backend/alembic.ini check
```
